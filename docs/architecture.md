# 核心职责与正确性

`domain` 定义带版本的来源、课表、候选、冻结选择和 placement；原始文本与网格字母分开。当前答案域为至少两字符的明确 ASCII 字母词；空格、标点、其他字母、重复主词、单字符词等返回明确待决定状态，不做删改或规范化。

`ingest` 通过 pdfplumber 表格单元格与字符位置恢复字段，保留全部原始单元格、表格外标题、字符对象、定义、发音、FORMS、例句和候选。候选只按原有逗号分隔，排版空白可以整理。覆盖检查核对原始序号、每个非空白字符的唯一归属、每字段字符的空间行序，与单元格字符串及 Poppler bbox-layout 坐标词序逐一对照；页字符统计只作辅助诊断。嵌套的推断单元格若引用完全相同的源字符，只合并其重复索引，原始解析结果仍保留在私人报告。导入器针对明确的编号词条表格；未知表格结构会要求检查，不用 OCR 猜测。

`clues` 固定数字回环地址、禁用代理和重定向，允许的接口仅为本机 Ollama 的版本、模型目录、已加载状态、模型信息和对话。JSON Schema 和 Pydantic 约束输出形状，业务校验进一步证明每词一次、候选属于该词。候选正文、标签和文件名均不由模型生成。上下文/输出预算随完整词条大小增长，必要时按词条分批；无效响应有限重试，不修补猜测。冻结版本绑定原件、课表、模型 digest、提示词和参数，并明确引用唯一 selection_run_id、实际请求/schema 哈希及采用的响应。每次运行和尝试文件均不可覆盖，不扫描最大 attempt 代替证据关联。

`solver` 为每词枚举两个正向方向的所有网格内 placement，每词恰选一个。按格子、方向、字母索引构造约束，没有 placement 笛卡尔积冲突表。同向占用和不同向字母一致性在格子处约束；每对相邻占用格必须有真实答案跨过该边，因此合法交叉不会被误禁，额外连续条目不能产生。

每对共享字母下标建立布尔交叉变量，与两字符的行列相等及方向不同**双向等价**。坐标和方向又与所选 placement 严格关联。词图上的双向非负流仅可经过真实交叉，逻辑根供给其余词各一单位，保证全图连通。逻辑根未固定坐标。完整域不做硬对称剪枝，不限制对角相邻，不强制横纵比例；有界启发式只产生提示，不能证明无解。

第二份排除第一份完整交叉指纹，而不是只排除坐标。独立验证器还以字母和答案归属计算八种几何变换的平移规范化表示。回文导致的等价副本会被拒绝；求解器仅排除该副本仍符合正向拼写的具体几何变换和合法平移，不封禁更大的指纹类。第一份与第二份没有共同最高美观分数限制。默认限制单任务、有限 CPU worker；回归可用单 worker 与固定 seed。

`validation` 不调用求解器几何函数。它从 placements 重建格子，扫描最大连续条目，重建交叉图，遍历连通性，重新编号并检查交叉指纹与几何差异。同起始格共享一个题号，横纵栏各自保留一条线索。

`pdf` 从原件向量表格、文字位置和实际页面框建立指纹绑定的私人坐标配置。原模板不重绘、不栅格化。新增字母按唯一占用格绘制一次，编号按唯一起点绘制一次，使用依赖自带且可嵌入的 Vera 字体。两栏排版先测量，最小线索字号为 11pt；容量纳入求解约束，长内容不会删改或截断。当前校准器明确拒绝不能可靠定位的模板、非零 MediaBox 原点、含交互注释或可选内容层的模板；不会静默改造。

`pdf_validation` 不调用生产 `plan` 或 `export_pdf`。它从原模板坐标、独立重建的格子/编号和冻结候选推导参考内容。共享信任仅包括只读的嵌入字体和排版规则；验证器用小型参考叠印绘制器构造可信图像，而不复制整个业务导出引擎。

最终 PDF 的文字层必须保留原模板字符并恰好匹配新增文字。模板允许变化范围由参考几何和可信字体推导，绝不接受被检 PDF 自报的大字符框。PDFium 和 Poppler 各自在固定倍率下将实际成品与参考成品比较；两种引擎之间不作逐像素相等要求。缺笔画、遮挡、不可见文字、错误字体 glyph 即使保留正确 Unicode 也不能通过。预览和差异图仅存私有域，人工状态单独记录。

`supervisor` 为每个任务创建 0700 临时目录、0600 通信文件，父进程只检查路径、文件类型、字节数和有限配置。输入复制为本任务只读快照后才交给解析器，哈希与解析使用同一份字节。显式 Python launcher 先应用 RLIMIT 再导入解析库，独立进程组和守护进程处理墙钟超时、取消及父进程消失；只回收本任务后代。IPC、stdout/stderr、单文件和临时总量均有上限。正常/失败路径清理自身目录；进程被强杀留下的带所有者标记目录由后续调用在确认原进程已退出后清理。它是资源监督，不承诺系统调用隔离或抵御解析库代码执行漏洞，没有改变内核、AppArmor 或系统配置。

`storage` 约束私人路径和标识，拒绝路径穿越、符号链接和覆盖原件，采用私人目录权限、临时文件写入与 fsync。独占文件锁将任务并发限制为一。成套产物先在私人 staging 中完成，验证清单与两份哈希后用同文件系统目录重命名一起发布。中断留下 staging 或完整结果，不留下标记成功的半套结果。`execution` 用独立 attempt、进程启动标识、周期心跳和取消标记管理生命周期。发布锁确定取消与完整目录发布的先后关系，发布后清单权威高于阶段状态。`services` 保存固定请求身份，可恢复两份已验证布局；不承诺保存 CP-SAT 搜索树。CLI 只作参数与状态转换。

## 后续产品接口与验收边界

后续 FastAPI 和独立 worker 应调用同一服务层。任务接口应映射导入、冻结选择、生成、取消、状态、验证与重建；持久化接口需要 SQLite 原子声明执行所有权、租约/心跳、幂等请求键、重试和重启核验。当前文件锁和阶段快照足够本地 CLI 单任务使用，尚未实现后台 worker、SQLite 调度或开机恢复服务。

前端方向为 React/TypeScript 的响应式 Web/PWA，覆盖现代手机、平板和桌面浏览器。使用自托管 PDF.js 在同页展示双份 PDF；下载提供正确名称与真实 PDF 字节。支持文件分享 API 的浏览器可调用系统分享，否则继续提供下载；不生成公开链接，不假设各浏览器安装和分享能力一致。PWA 默认仅缓存静态界面，不持久缓存私人词表或 PDF。

后端仅监听回环，由获准的私有 Tailscale Serve HTTPS 入口访问，禁止 Funnel、公网端口转发和暴露 Ollama。部署前核对端口和已有路由，不能覆盖现有服务。权限必须覆盖 API、任务、PDF 预览、下载和 Range；明确用户/设备授权，校验来源，只在可信入口接受代理身份，限制请求和路径。字体、脚本、图标、阅读器全自托管，无追踪/CDN/云模型或转换服务。

生产阶段还需独立验收：关闭浏览器或断网后任务继续；模型不可用不影响已有文件和冻结线索重建；SQLite 一致性备份；重复请求不会混合版本；systemd 开机启动、异常恢复、网络/模型等待、资源限制和日志轮转。任何睡眠、电源、自启、密钥策略或系统服务变化需另行确认。本阶段未部署这些能力。

## 版本迁移与有界美观

旧 schema 1 课表/冻结的版本哈希保持原算法。schema 2 课表业务身份排除检查时间与诊断报告哈希，检查仍比较字段归属、字符串和候选顺序。旧 `ingest/lesson.json`、`clues/frozen.json` 和旧结果按只读回退路径读取；新发布只写不可变版本目录与 `current.json`。检查、验收和性能证据分别保存在独立诊断或运行目录。旧模型响应只有唯一完整匹配时才报告有限的历史关联；缺失请求/digest绑定时不能宣称完整 provenance，也不因此丢弃结构正确的 PDF。

任务请求身份包含来源、课表内容、冻结及证据版本、模板、前缀顺序、字体和交付规则。可延长时间/资源预算和线程数不纳入身份。完整清单必须含全部必需快照与哈希、正确任务 ID 和两份唯一名称，并作跨快照一致性检查；空 hash 字典不能通过。历史 verify/rebuild 使用结果快照，不读取当前新课表代替。

排版容量只使用必要下界与安全的方向不可行判定；最终题号和换行由实际布局精确检查。宽度失败按 12→11.5→11pt 回退，缺失字形不会被吞掉。若具体布局的两栏高度不够，只排除此具体布局继续搜索，不能把保守高估误称全问题无解。

完整双份布局先保存，再进入可关闭的有界优化。目标按真实交叉数、包围面积、居中偏差依次处理。每个候选都重新验证结构、两份差异和排版，且相对当前布局词典序不退化才采用。预算耗尽保留已验证结果；内部异常记录明确 fallback，任务取消仍为 CANCELLED。没有对整个词典序目标完成证明时只报告 IMPROVED_NOT_PROVEN 或 BOUNDED_NO_IMPROVEMENT，不把 satisfaction OPTIMAL 当作美观最优。
